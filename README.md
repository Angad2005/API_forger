# API Forge Pro ✨

A powerful, single-file, browser-based API testing client, supercharged with Google's Gemini API for intelligent test and documentation generation.

API Forge Pro is a complete, standalone API testing environment that runs entirely in your web browser. It requires no installation, no backend, and no account. All your data is stored securely in your browser's local storage. It's designed for developers who need a portable, powerful tool that's easy to use and share.

## Key Features

### Core API Client Functionality
- 🗂️ **Collections & Folders**: Organize your API requests into collections and nested folders for better project management.
- 🌍 **Environment Variables**: Define variables like `{{baseURL}}` or `{{authToken}}` for different environments (local, staging, production) and switch between them with a dropdown.
- 🔐 **Advanced Authentication**: Built-in helpers for Bearer Token, Basic Auth, and API Key authentication (in headers or query params).
- 📖 **Request History**: Automatically saves a history of your sent requests for quick access and re-use.
- 📥/📤 **Import & Export**: Share your entire workspace with teammates or back up your work by exporting collections and environments to a single JSON file.

### ✨ AI-Powered by Gemini
- 🤖 **AI-Generated Tests**: After receiving a JSON response, click "✨ Generate Tests". Gemini analyzes your request and response to automatically write JavaScript tests that validate the status code, response structure, and data types.
- ✍️ **AI-Powered Documentation**: Click "✨ Help Me Document" on any request. Gemini will generate a concise description of the endpoint's purpose and a sample cURL command, helping you document your APIs faster.

## Why API Forge Pro?
- 🚀 **Zero Installation**: It's a single HTML file. Download it, open it in your browser, and you're ready to go.
- 📦 **Fully Portable**: Carry your entire API testing suite on a flash drive, check it into a repository, or host it on a static site.
- 🔒 **Private & Secure**: All request data, collections, and history are stored only in your browser's localStorage. No data is sent to any external servers, except for the APIs you are testing and the optional calls to the Gemini API.
- 🧠 **Intelligent Assistant**: Go beyond simple requests. Leverage the power of a large language model to automate the tedious parts of API development like writing tests and documentation.

## Getting Started
It couldn't be simpler:

1. **Download**: Get the `api_forge.html` file.
2. **Open**: Open the file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. **Done**: Start creating requests!

## How to Use

### 1. Your First Request
- Click **New** in the Collections panel to create your first collection.
- Hover over the new collection and click **+R** to add a new request.
- Select the new request from the list.
- Fill in the **Method**, **URL**, **Headers**, **Auth**, and **Body** as needed.
- Click **Send** to see the response.
- Give your request a name and click **Save**.

### 2. Generating Tests with AI
- Run a request that successfully returns a JSON body.
- In the right-hand response panel, navigate to the **Tests** tab.
- Click the **✨ Generate Tests** button.
- Review the AI-generated JavaScript tests that appear in the text area. The tests will run automatically on the next request.

### 3. Creating Documentation with AI
- Select a saved request you want to document.
- Below the main request tabs, click the **✨ Help Me Document** button.
- A modal will pop up with a description and a sample cURL command generated by Gemini.

## Technical Stack
